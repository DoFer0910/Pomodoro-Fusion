# Yield（イールド）

**収益が見えるポモドーロタイマー。**

在宅ワーク・フリーランス・学習の生産性を最大化する、デスクトップ型ポモドーロタイマーです。
「稼ぐ（Earn）」と「没頭（Immerse）」の2つのモードで、目的に合わせた集中環境を提供します。

</div>

---

## ダウンロードとインストール

1. [**Releases ページ**](https://github.com/DoFer0910/Pomodoro-Fusion/releases/latest) から最新版の `Yield Setup <version>.exe` をダウンロードします。
2. ダウンロードした `.exe` を実行し、ウィザードに従ってインストールします。
3. インストール後、デスクトップまたはスタートメニューの **Yield** から起動できます。

> **「WindowsによってPCが保護されました」と表示された場合**
> 本アプリは現時点でコード署名を行っていないため、初回起動時に Microsoft Defender SmartScreen の警告が出ることがあります。
> 「詳細情報」→「実行」を選択すると起動できます。

対応OS: **Windows 10 / 11（64bit）**

## 特徴

### 🎯 2つの集中モード
- **稼ぐ（Earn）** — フリーランス・副業向け。作業時間を時給換算し、リアルタイムで収益を可視化します。
- **没頭（Immerse）** — 学習・研究向け。金額表示を排除し、純粋な集中時間だけを記録します。

### 💻 デスクトップに最適化された体験
- **コンパクトモード** — ウィンドウを極小サイズ（300×300）の透過ウィンドウにして画面の隅に常駐。作業の邪魔になりません。通常モードに戻すと、以前のサイズと位置が自動で復元されます。
- **常に最前面（Always on Top）** — トグル一つで、ウィンドウを他のアプリの手前に固定できます。

### ⏱️ 高機能ポモドーロタイマー & ToDo
- 作業時間・休憩時間を自由にカスタマイズ。長い休憩の間隔も設定可能。
- **ToDoリスト** — タスクごとの見積もり・実績管理（未完了／完了フィルタリング付き）。
- **プロジェクト管理** — 案件や学習科目ごとにプロジェクトを作成し、色分け・時給設定が可能。
- **手動時間入力** — 履歴画面から過去の作業セッションを手動で追加できます（タイマーの押し忘れに対応）。

### 🤖 Claude Code 連携
- プロジェクトに **リポジトリのパス** を登録しておくと、そのリポジトリで作業した [Claude Code](https://claude.com/claude-code) のセッション時間を自動で集計し、該当プロジェクトに紐づけられます。
- プロジェクト一覧の **「Claude Code 同期」** ボタンで取り込みます。離席（イベント間隔が5分以上空いた区間）は作業時間から自動的に除外されます。

### 📊 充実した統計機能
- **実績カレンダー** — GitHub の草（Contributions）のように、日々の頑張りをヒートマップで可視化。
- **プロジェクト別集計** — どのプロジェクトにどれだけ時間を使い、いくら稼いだかを円グラフで分析。
- **CSVエクスポート** — 確定申告や日報作成に使える詳細な作業ログ（プロジェクト名・収益を含む）を出力。

## 使い方のヒント

1. **モード選択** — ヘッダーの切り替えスイッチで「稼ぐ」か「没頭」を選びます。
2. **コンパクトモード活用** — 作業中はヘッダーの四角いアイコンをクリックしてコンパクトモードへ。画面の隅に置いて集中しましょう。
3. **プロジェクト設定** — 統計タブからプロジェクトを追加し、時給を設定すると、より正確な収益管理ができます。
4. **手動記録** — タイマーを押し忘れたら、履歴タブの「セッションを手動追加」から時間を記録できます。
5. **達成感** — タイマー完了時、稼ぐモードではチャリーンと収益が加算されます！

## 開発者向け

### 技術スタック
- **Electron** + **Next.js（静的エクスポート）** + **React 19** + **TypeScript**
- UI: **Tailwind CSS v4** / **shadcn/ui**
- データは全てクライアントサイドに保存（Web版は `localStorage`、デスクトップ版は `electron-store`）。バックエンドはありません。

### 前提条件
- Node.js v20 以上を推奨

### セットアップ
```bash
npm install
```

### 開発（Web版）
ブラウザで動作確認します。ホットリロードが有効です。起動後 `http://localhost:3000` を開きます。
```bash
npm run dev
```

### 開発（デスクトップ版 / Electron）
Electron アプリとして起動します。
```bash
npm run dev:electron
```

### テスト
```bash
npm test
```

### ビルド（Windowsインストーラー作成）
Windows 用インストーラー（`.exe`）を生成します。出力先は `dist/`（`Yield Setup <version>.exe`）。
```bash
npm run build:electron
```

### リリース（自動配布）
`v*` 形式のタグ（例: `v0.3.21`）を push すると、GitHub Actions が Windows 上で自動ビルドし、生成した `.exe` を GitHub Release に公開します。
```bash
git tag v0.3.21
git push origin v0.3.21
```

> アプリアイコンを更新する場合は `build/icon-source.svg` を編集後、`node build/generate-icon.mjs` で `.ico` を再生成します（`sharp` と `png-to-ico` が必要）。
