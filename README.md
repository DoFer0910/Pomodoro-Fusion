# イールド (Yield)

在宅ワーク・学習の生産性を最大化する、収益可視化機能付きポモドーロタイマーアプリです。
「稼ぐ (Earn)」と「没頭 (Immerse)」の2つのモードで、目的に合わせた集中環境を提供します。

## 特徴

### 🎯 2つの集中モード
*   **稼ぐ (Earn)**: フリーランス・副業向け。作業時間を時給換算し、リアルタイムで収益を可視化します。
*   **没頭 (Immerse)**: 学習・研究向け。金額表示を排除し、純粋な集中時間を記録します。

### 💻 デスクトップに最適化された体験
*   **コンパクトモード**: ウィンドウを極小サイズ (300x300) にし、作業の邪魔にならないように画面の隅に配置できます。背景は透過され、デスクに馴染みます。
*   **常に最前面 (Always on Top)**: トグルボタン一つで、ウィンドウを常に他のアプリの手前に固定できます。

### ⏱️ 高機能ポモドーロタイマー & ToDo
*   作業時間・休憩時間は自由にカスタマイズ可能。
*   **ToDoリスト**: タスクごとの見積もり・実績管理（未完了/完了フィルタリング機能付き）。
*   **プロジェクト管理**: 案件や学習科目ごとにプロジェクトを作成し、色分けや時給設定が可能。

### 📊 充実した統計機能 (バージョン 0.2.2以降)
*   **実績カレンダー**: GitHubの草（Contributions）のように、日々の頑張りをヒートマップで可視化。
*   **プロジェクト別集計**: どのプロジェクトにどれだけ時間を使い、いくら稼いだかを円グラフで分析。
*   **CSVエクスポート**: 確定申告や日報作成に使える詳細な作業ログ（プロジェクト名、収益含む）を出力。

## 起動方法

### 前提条件
*   Node.js (v20以上推奨) がインストールされていること

### 開発用 (Web版)
ブラウザでの動作確認用です。ホットリロードが有効です。

```bash
npm install
npm run dev
```
起動後、`http://localhost:3000` にアクセスしてください。

### 開発用 (デスクトップ版 / Electron)
Electronアプリとしての動作確認用です。

```bash
npm run dev:electron
```

### ビルド (デスクトップ版インストーラー作成)
Windows用のインストーラー (`.exe`) を生成します。

```bash
npm run build:electron
```
生成されたファイルは `dist` フォルダに出力されます (`Yield Setup <version>.exe`)。

## 使い方のヒント
1.  **モード選択**: ヘッダーの切り替えスイッチで「稼ぐ」か「没頭」を選択します。
2.  **コンパクトモード活用**: 作業中はヘッダーの「四角いアイコン」をクリックしてコンパクトモードへ。画面の隅に置いて集中しましょう。
3.  **プロジェクト設定**: 統計タブからプロジェクトを追加し、時給を設定することで、より正確な収益管理が可能です。
4.  **達成感**: タイマー完了時、稼ぐモードではチャリーンと収益が加算されます！
